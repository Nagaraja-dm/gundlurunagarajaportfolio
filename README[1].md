# Nagaraja Portfolio

A fast, responsive static portfolio for GitHub + Vercel.

## Files
- `index.html` — portfolio content
- `style.css` — dark performance-marketing visual theme
- `script.js` — small scroll-reveal interaction
- `assets/profile.jpg` — add your professional profile photo here

## Deploy to Vercel
1. Create a GitHub repository.
2. Upload all files/folders from this project.
3. Import the repository into Vercel.
4. Framework preset: **Other** / static site.
5. Build command: leave empty.
6. Output directory: `.`

## Before publishing
- Replace `assets/profile.jpg` with your final LinkedIn/profile photo.
- Replace the LinkedIn profile URL in `index.html` with your actual personal LinkedIn profile URL (the current supplied URL opens LinkedIn's feed).
- Add verified certification links if you want a Certifications section.
- Only publish claims/results that you can confidently explain in an interview.
